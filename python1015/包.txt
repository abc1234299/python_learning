1.包
    包是一种管理python模块命名空间的形式
    通过使用.模块名来构造Python模块命名空间的一种方式。
    A.B 表示名为A的包中名为B的子模块
    包与文件夹相似，不过该文件夹下必须有一个__init__.py文件
2.模块导入
    (2)带包的模块导入
    a.全局导入
        导入包中模块的所有成员
        语法：
        import 包名.模块名.成员名 [as 别名]
        注意：
            使用import时，除最后一项外都必须是包。最后一项可以是模块或者包，
            但不能是类、函数或变量
            如果最后一项是包，那么必须在被导入包的__init__.py文件中，
            指定导入包中的哪些模块。只是python导包的一个优化机制，避免导入过多模块。
            并且在__init__.py中指定导入模块的时候，建议使用相对路径
                from . import circle
    b.局部导入
    从包中导入模块
        语法：
        from 包名 import 模块名 [as 别名]
    从包中模块导入功能
        语法：
        from 包名.模块名 import 成员名 [as 别名]
         
    from import * 从包中导入模块
    此时包的__init__.py定义了__all__,运行from import* 时，它就是被导入的模块名列表
    from 包名.模块名 import *
    同时要在__init__.py中添加
    __all__ = ["circle"]
