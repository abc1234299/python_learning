1.模块
    python中以.py结尾的源文件即为一个模块Module。其中可以包含变量、函数和类等。
    通常我们将实现某一特定功能的代码放置在一个文件中作为一个模块。
    编写好一个模块后，只要是使用该功能的程序都可以导入这个模块实现。
    另外，使用模块也可以避免名称冲突，相同名字的函数或者变量可以分别存放在不同的模块中
2.创建模块
    模块名区分大小写，且不能与Python自带的标准块重名

    (1)不带包的模块导入
        a.全局导入
            导入模块的所有成员，通过 模块名.成员名的方式访问。
            即使多次使用import导入同一个模块，模块也只会被导入一次

            语法：
            import 模块名 [as 别名]

        b.局部导入
            指定导入模块的部分成员，直接通过成员名的方式导图。
            只能使用其导入的成员，未导入的成员不能使用。
            如果多个模块中存在重名成员，后一次导入会覆盖前一次导入

            a.语法：
            from 模块名 import 成员名1 [as 别名]，成员名2 [as 别名]

            b.语法：
            from 模块名 import *
            导入模块中所有不以单下划线开头的成员，直接通过成员名的方式访问
3.模块的搜索顺序
    (1)当前目录
    (2)PYTHONPATH环境变量中的目录
    (3)包含标准Python模块以及这些模块所依赖的任何extension module的目录
    使用一下方式查看模块搜索顺序
    import sys
    print(sys.path)
    也可以通过sys.path.append(路劲)向sys.path中临时添加路径
4.__all__
    使用from import * 导入模块时，可以在被导入的模块中使用 __all__ 设置哪些内容
    可以被导入。__all__ 的设置只针对使用from import * 导入模块时有效
    计算是当前成员是以_开头，如果声明在__all__中，也可以被外部访问
5.__name__
    __name__是一个特殊的内置变量
    当一个python文件被直接运行时，该文件的__name__属性值为"__main__"
    当一个python文件作为模块被导入时，__name__属性会被设置为改模块的名称（即文件名，不包含.py后缀）
    如果在导入其他模块的时候，不需要被导入模块的测试代码被执行，
    那么可以在被导入模块中加如下分支判断
        if __name__ = "__main__":
            执行测试语句
6.dir()
    内置函数，主要用于列出对象的属性和方法，或者列出当前作用域中定义的名称，
    并以一个字符串的形式返回
